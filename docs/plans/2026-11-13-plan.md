## 上下文中心（会话成分页）— 设计定稿与实施计划

### 0. 结论与已确认的选择

- **形态**：全屏中心页（`work-area` 覆盖层，与记忆中心 / 自动化中心同级），不是预览标签、不是对话框。
- **范围**：全量六区 —— 占用总览 / 系统提示词 / 工具声明 / 资源注入 / 对话消息 / 运行参数。
- **只读，不提供复制/导出**（按用户选择）；不支持跨会话历史。
- **只跟随焦点会话**（分屏时即焦点格），打开、切会话、手动刷新、回合从运行中回到就绪时各拉一次。
- **可交互设计预览已产出**：`outputs/context-center-design.html`（已在内置浏览器打开，可切明暗、切分区、展开提示词块 / 工具 schema、筛工具来源）。预览截图：`outputs/context-center-live-hero.png`、`context-center-live-tools.png`、`context-center-live-entry.png`。
- 预览放在 `outputs/`，只是设计稿，**不进入构建**；实现时按本文第 3 节落地。

### 1. 页面结构（定稿）

页面外壳：`data-pane="context-center"`，固定头 + 左成分导航 + 右滚动内容。

**头部**：图标 + 「上下文中心」+ 会话标题 / 助手 / 模型 / 「更新于 HH:MM:SS」；右侧「回合结束后自动刷新」提示、刷新按钮、关闭按钮。

**左导航**（不是 tab，滚动时高亮）：占用总览（59.3%）、系统提示词（~2.9K）、工具声明（~6.2K）、资源注入（6 类）、对话消息（~108.9K）、运行参数（18 项）；底部两行脚注：只读 / 估算 ≈4 字符每 token。

**① 占用总览**：大号百分比 + `≈x / y tokens`；系统 / 工具 / 消息三段堆叠条 + 图例；右侧事实卡（缓存命中、消息数、压缩次数、轮数）；一行说明「总量锚定真实 usage、三段明细是本地启发式、加总不必相等」。

**② 系统提示词**：标题行（字数 · token · 分段数、冻结徽标、分段/全文切换）。
- `preamble` 卡：按 7 个构建器块切分（助手人设 / 技能清单 / 工具编排 / 输出格式 / 子智能体清单 / 记忆索引 / Div 气泡规范），每块显示来源、字数、token、占比条，可展开读原文；未出现在本会话冻结提示词里的块归入「本会话未注入」。
- 其余真实分段卡：`cwd`、`mcp_servers`（以及未来任何 XML 分段），显示来源与正文。
- 「每回合尾部注入」卡：界面主题一行、Div 合规重申；**措辞为「下一回合将注入（按当前配置）」**，并注明「请求时注入、不进转录」；计划模式叙事与钩子 additionalContext 走对话尾部，不进系统提示词（脚注说明）。
- 「运行中追加的系统消息」卡：工具集变化等 Pi system 消息补丁（通常为空态）。
- 全文视图：`session.systemPrompt` 原文，一个 `<pre>`，按出现顺序。
- 脚注：分段来自转录里真实的 system 消息 sections（折叠后当前状态），**不是按当前配置重算**；技能/记忆清单在会话创建时冻结。

**③ 工具声明**：标题行（N 个声明 · token · 另有 M 个脚本可调未声明）；来源筛选 chips（全部 / 内置 / 任务与记忆 / 自动化 / 浏览器 / SSH / 团队 / 设计·脚本 / MCP）；按来源分组的卡片，每行：名称（等宽）+ 描述单行 + ~token + 展开箭头；展开后显示完整描述、参数 schema（pretty JSON）、promptGuidelines。底部「已注册、未声明（不占前缀）」列出 codemode/deferred 工具。脚注：token = 声明 JSON/4 + 4，清单取自 `session.state.tools`（模型实际看到的声明），不是注册表全量。

**④ 资源注入**：2 列卡片 —— 技能（启用/总数，逐条名字 + 一行描述 + 启用徽标）、子智能体（名字/颜色/模型）、钩子（事件 + 动作 + scope + 是否拦截）、MCP 服务（连接态、传输、曝光 direct/codemode、工具数）、斜杠命令、长期记忆（核心/标准/归档计数、索引字数与预算、~token）。脚注：清单来自**当前配置**；只有技能/子智能体/记忆进入提示词且在会话创建时冻结；钩子与 MCP 是运行期行为；不展示 headers/env/凭据。

**⑤ 对话消息**：角色表（用户 / 助手 / 工具结果 / 系统消息（首条））：条数、估算 token、占比条；「谁在吃上下文」前 5 条（角色 + 名称/时间 + 截断预览 + ~token）；事实 chips（图片数、工具结果条数、最近一次请求输入、压缩次数）。脚注：复用 Pi 的 `estimateTokens`；首条系统消息携带系统提示词，Pi 现有口径里同时计入消息段，页面照实展示、不二次扣减。

**⑥ 运行参数**：两列定义表，16 项：模型、思考等级、上下文窗口、最大输出、访问模式、计划模式、Div 气泡、团队模式、电脑控制、设计模式、记忆注入、技能注入、钩子、Shell 可中止、缓存命中；对「技能注入 / 记忆注入」标冻结；不编造 Pi 无法给出的字段。

**空态/错误态**：无工作区 → 「先打开一个话题」；会话不在 liveRecords → 主进程回可读错误，页面给「重新打开」提示 + 刷新按钮；加载中保留旧数据 + 细 spinner。

**入口**：
1. 输入框左下角「上下文 x%」弹层底部新增一行「查看全部成分」`data-control="context-center-open"`（点后关弹层并打开页面）；
2. 侧栏底部导航新增「上下文」按钮（展开态 + 折叠窄条图标各一处），`data-control="context-center-open-nav"`；
3. 命令面板新增「查看会话上下文」（`searchOnly: true`，关键词含 上下文/提示词/工具/schema/token）。

**刷新**：页面打开、`snapshot.sessionId` 变化、手动刷新、`busy` 从 true→false（回合结束）各请求一次；300ms 防抖；流式期间不重复拉。

**主题**：新增 `data-pane="context-center"` 与控件钩子 `context-center-open` / `context-center-open-nav` / `context-center-close` / `context-center-refresh` / `context-center-prompt-view` / `context-center-tool-filter`；类名 `.context-center*` 自包含；配色只走现有语义 token；CJK 连续文本 ≥ 11px，10px 只给徽标/数字。

### 2. 数据与协议

**新增协议**（`src/shared/protocol.ts`）：

```ts
export interface ContextInspection {
  at: number;
  sessionId: string;
  agentId: string;
  agentName: string;
  model?: { provider: string; id: string; contextWindow?: number; maxTokens?: number };
  thinkingLevel: ThinkingLevel;
  usage?: ContextUsage;
  prompt: {
    text: string;                     // session.systemPrompt 原文
    blocks: ContextPromptBlock[];     // 7 个构建器块（present=false 表示本会话未注入）
    sections: ContextPromptSection[]; // 折叠后的 XML 分段（cwd / mcp_servers / …）
    extraSystemMessages: { chars: number; preview: string }[];
    turnInjections: ContextTurnInjection[];
  };
  tools: {
    declared: ContextToolDeclaration['declared'][]; // 见下：name/description/parameters/tokens/exposure/source/guideline
    undeclared: { name: string; exposure: string; source: string }[];
  };
  messages: {
    total: number;
    byRole: { role: "user" | "assistant" | "toolResult" | "system"; count: number; tokens: number }[];
    top: { role: string; tokens: number; preview: string }[];
    images: number;
  };
  runtime: { label: string; value: string; note?: string; frozen?: boolean }[];
}
```

（`ContextPromptBlock` = `id/label/origin/present/chars/text`；`ContextPromptSection` = `name/origin/chars/text`；`ContextTurnInjection` = `label/origin/active/chars/text?`；`ContextToolDeclaration` = `name/description/parameters/token/exposure/source/guideline?`。）

**命令与响应**：
- `RuntimeCommand` 增 `{ type: "session.inspect"; requestId: string; sessionId?: string }`
- `RuntimeMessage` 增 `{ type: "session.inspect-result"; requestId: string; sessionId?: string; inspection?: ContextInspection; error?: string }`
- 主进程不需要改：命令走既有 `runtime:send` 转发，消息按既有 `runtime:message` 回渲染端。

**取值来源（utility 进程）**：
- 提示词：`session.systemPrompt`；从 `session.state.messages` 的 system 消息**按序折叠** `sections`（后出现的覆盖同名，`null` 删除）得到真实分段；preamble 交给纯函数切块。
- 切块：按固定顺序的标记串定位（助手人设取 `record.agent.systemPrompt` 的开头；技能块「以下 Skill 可用，需要时先用 read…」；「【工具编排】」；「【输出格式】」；「以下自定义子智能体是 delegate_agent 的唯一委派对象」；「【长期记忆（memory_* 工具）】」/「【长期记忆索引（项目库 + 助手库）】」；「【Div 气泡模式：」）。块文本 = 本块起点到下一块起点；找不到的块 `present:false`，用当前配置重算的文本展示但明确标注。搜索只从上一个边界之后进行，乱序标记跳过。
- 尾部注入：`buildDivModeReminder(divMode)`、`buildUiThemeContextBlock(divMode, uiThemeContext)`（divMode 按 `record.im ? "off" : record.agent.divMode` 推导）；文案写「下一回合将注入」。
- 工具：声明 = `session.state.tools`（name/description/parameters），逐个 `estimateToolTokens([tool])`；注册表信息 = `session.getAllTools()` 按 name 取 `exposure/promptGuidelines/sourceInfo.path`，`source` 映射为 builtin（`builtin:` 前缀）/ app（`<inline:`）/ mcp（MCP 工具名或 mcp 来源）/ other；未声明 = 注册表 − 声明。
- 消息：`session.state.messages`，逐条 `estimateTokens`；图片按 content 数组统计；top 预览截 120 字；`parameters` 单工具超过 6000 字截断并注明。
- 运行参数：record/settings/model + `settings.memory`、`resources.hooks`、`divMode`、团队/电脑/设计模式、`cacheHitRate`。
- **安全**：不返回 MCP headers/env/凭据，不展开图片 base64，不返回工作区外的路径。

**渲染端**：store 新增切片 `contextInspection`（requestId/sessionId/loading/data/error），按 requestId 丢弃过期结果；页面 + `lib/context-inspection-view.ts`（工具分组/来源标签/占比/截断等纯函数）。

### 4. 风险与取舍

- **体积**：提示词 + 57 个 schema 约几十 KB，只在按需命令里传，绝不进 50ms 快照帧；schema 与预览有截断上限。
- **SDK 形状漂移**：`state.messages` 的 sections 与 `state.tools` 是 Pi 的投影，用真实会话机制测试钉住；不依赖私有字段。
- **冻结 vs 当前**：页面明确区分「会话创建时冻结」（提示词里的技能/子智能体/记忆）与「当前配置」（资源清单），不把设置页的现状冒充成模型看到的内容。
- **口径差异**：总览的三段明细沿用 Pi 的现有定义（消息段含首条系统消息），页面在消息区照实标注、不二次扣减；明细与占用总量不同源，UI 不宣称相等。
- **分屏焦点**：点分屏格子里的徽标会先触发该格聚焦（`onFocus`），页面跟随快照 sessionId；若激活是异步的，页面会在 sessionId 变化时自动重拉，可能有一帧旧数据（保留旧数据 + spinner）。
- **隐私**：只读、不导出（按用户选择）；不展示密钥/请求头；提示词含记忆正文，属于用户数据，不落新文件、不写日志。
- **主题契约**：新增 pane 与控件钩子必须同步 `docs/theme-guide.md`；样式只用 token，避免深色/壁纸下不可读。
- **不做**：不改提示词拼装逻辑；不改 `context-breakdown` 的既有口径；不做跨会话历史快照；不做复制/导出；不新增全局快捷键。

### 5. 假设

- 形态按预览中的全屏中心页实现；若改右侧预览标签，属于另一套改动（动 PreviewTarget/标签持久化），不在本计划内。
- 当前 Pi 版本 1.4.0 的 `session.systemPrompt` / `session.state.messages` / `session.state.tools` / `getAllTools()` / `getContextUsage()` 形状如仓库现有代码所依赖；机制测试会先把这条钉住。
