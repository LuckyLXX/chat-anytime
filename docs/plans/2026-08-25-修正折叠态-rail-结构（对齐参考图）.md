# 修正折叠态 rail 结构（对齐参考图）

## 背景与目标
你的反馈：折叠态顶部结构不对。期望**最顶部是展开按钮**——默认显示项目名「CA」品牌标记，鼠标移上去时切换为展开图标（并高亮、提示可点击展开）；底部参考图还有一个入口图标。
当前实现：顶部是「新增会话」，展开按钮在底部 → 需重构 rail 顺序。

修正后折叠态 `.sidebar-rail`（48px，其余 hover 浮层/0.18s 动画/重启默认展开均不变）：
- **顶部**：展开按钮（默认显示品牌「CA」，hover 变为展开图标 + 高亮，点击展开侧边栏）
- **中段**：新增会话（accent）/ 话题 / 助手（保持不变）
- **底部**：一个入口图标按钮（参考图底部样式）——我放置为「设置」（title=设置，点击打开设置对话框）

## 实施步骤

### 1. `App.tsx`（rail 结构）
- 在 `sidebar-rail` 内、`sidebar-rail-items` 之前插入顶部展开按钮：
  `<button type="button" className="rail-brand" data-control="sidebar-expand" title="展开侧边栏" aria-label="展开侧边栏" onClick={() => setSidebarCollapsed(false)}><span className="rail-brand-mark">CA</span><PanelLeftOpen className="rail-brand-expand" size={18} /></button>`
- `sidebar-rail-items`（新增会话/话题/助手）保持不变。
- `sidebar-rail-footer`：把当前的「展开按钮」替换为设置按钮：
  `<button type="button" className="rail-icon" data-control="rail-settings" title="设置" aria-label="设置" onClick={() => setSettingsOpen(true)}><Settings size={18} /></button>`

### 2. `styles.css`
- 新增 `.rail-brand`（圆形品牌按钮，顶部居中，默认显示 CA）：
  `.sidebar-rail .rail-brand { display:grid; place-items:center; width:32px; height:32px; margin:0 auto 8px; border:1px solid var(--border-strong); border-radius:50%; color:var(--text); background:var(--surface); cursor:pointer; }`
- `.rail-brand-mark { font-size:11px; font-weight:800; line-height:1; }`
- `.rail-brand-expand { display:none; }`
- 两态切换（默认 CA → hover 展开图标 + 高亮）：
  `.sidebar-rail .rail-brand:hover { color:var(--accent-text); background:var(--accent-soft); border-color:var(--accent); }`
  `.sidebar-rail .rail-brand:hover .rail-brand-mark { display:none; }`
  `.sidebar-rail .rail-brand:hover .rail-brand-expand { display:grid; }`
- `sidebar-rail-items` 顶部 margin 微调（因顶部多了一个品牌按钮）。
- 其余 rail 样式（rail-icon/rail-new-session/flyout/壁纸）不动。

## 验证
- `npm test`（524）+ `npm run build` 全绿。
- 手工：折叠态顶部默认圆形「CA」，hover 变展开图标并可点击展开；中段新增会话/话题/助手；底部设置按钮可打开设置；hover 浮层、0.18s 动画、重启默认展开均不受影响。

## 风险与假设

- 其余实现（48px / hover 浮层 / 不持久化 / 主题契约 data-ui-sidebar-collapsed + --layout-sidebar-collapsed-width）保持不变。
