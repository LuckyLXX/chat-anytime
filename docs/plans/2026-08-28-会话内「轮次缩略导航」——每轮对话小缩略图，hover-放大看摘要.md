# 会话内「轮次缩略导航」——每轮对话小缩略图，hover 放大看摘要

## 背景与目标
针对**单个会话内部**（不是会话列表）。长会话里每一轮对话（一次用户提问 + 对应的 AI 回复）生成一个**小缩略图**；鼠标移到某个缩略图上会放大，显示该轮的**用户输入摘要 + AI 输出摘要**（各取前若干字符）。用于长会话下快速预览每一轮在聊什么、并定位跳转。

## 关键研判（已确认，纯渲染端可实现）
- 时间线用 `groupAssistantMessages`（`src/renderer/src/lib/chat-layout.ts`）把连续的 assistant 消息合并为一个视觉回复，所以"**一轮**"天然可界定：**以一个 `role="user"` 消息为锚点**，直到下一个 user 消息（提问 + 其后全部的 AI/工具回复）。
- 数据都在渲染端 `data.messages`（`ChatMessage[]`，含 `role`/`blocks`/`uuid`），无需主进程改动、无需额外读盘、不破坏协议与主题钩子。
- 时间线容器是 `div.timeline`（`timelineRef`），已有基于 `scrollTo` 的粘底滚动逻辑；给每轮首条消息加锚点后可用 `offsetTop` 定位滚动。

## 默认交互形态
在**会话时间线右侧贴边**加一条**垂直缩略导航条**（minimap 风格）：
- 每个缩略卡片对应一轮，默认显示为紧凑的小块（显示轮次序号或首字符）；hover 放大成一张浮出卡片，展示该轮「用户输入」省略预览 + 「AI 输出」省略预览（各取前 120 字符，保留换行/折叠空白）。
- 点击某个缩略图 → 时间线平滑滚动到该轮首条消息处（同时把 `stickToBottomRef` 置 false，避免被粘底逻辑拉回底部）。
- 拖到最底部的当前轮自动高亮；无历史轮次（空会话）不显示导航条。

## 实施步骤

### 1. 纯函数：轮次摘要切分（可单测）
新增 `src/renderer/src/lib/turn-summary.ts`：
```ts
export interface TurnSummary {
  key: string;          // 该轮首条消息 uuid/id，用于锚点与滚动定位
  index: number;        // 轮次序号
  userText: string;     // 用户输入文本摘要（text blocks 拼接，排除图片，截断到 maxPreviewChars）
  aiText: string;       // AI 输出文本摘要（text blocks 拼接，排除 thinking/tool-call，截断到 maxPreviewChars）
  messageCount: number; // 该轮涵盖的消息数
}
export function buildTurnSummaries(messages: ChatMessage[], maxPreviewChars = 120): TurnSummary[];
export function truncatePreview(text: string, maxChars: number): string; // 合并空白、保留首行、加省略号
```
规则：遍历 `data.messages`（已按 `groupAssistantMessages` 分组），`role=user` 开新一轮，后续 `role=assistant` 归入当前轮取文本，遇下一个 user 结束上一轮。

### 2. 时间线锚点
`ConversationPane.tsx` 的 `displayMessages.map` 里，给**每轮首条消息**对应的 `MessageView`/article 加一个定位钩子 `data-turn-key`（等于该轮首条消息的 `uuid ?? id`），供导航条点击时 `timeline.querySelector` 找 `offsetTop`。

### 3. 垂直导航条组件
新增 `src/renderer/src/components/TurnMinimap.tsx`：
- props：`turns: TurnSummary[]`、`activeKey?: string`（当前底部所属轮，可据 `data-turn-key` 与滚动监听估算）、`onNavigate(key)`。
- 渲染右侧贴边窄条 `data-pane="turn-minimap"`；每个轮次一个 `.turn-thumb`，内置 hover 放大卡片（绝对定位浮出，避免遮挡时间线）。
- `onNavigate` 回调到 ConversationPane：查锚点 `offsetTop`，`timeline.scrollTo({ top, behavior: "smooth" })`，并 `stickToBottomRef.current = false`。

### 4. 挂载与样式
- `ConversationPane.tsx` 在 `.timeline` 之外渲染 `<TurnMinimap>`（仅当 `turns.length >= 2`；单轮不显示，避免空占）。
- `styles.css`：`.turn-minimap`（窄条容器，透明背景、hover 才明显）、`.turn-thumb`（紧凑小块 + 浮出卡片）、`messageCount` 徽标、hover 放大动画（transform/opacity，cubic-bezier，遵循现有动效规范）；适配 `data-ui-density`。
- 主题契约：新增 `data-pane="turn-minimap"` 钩子与 `.turn-thumb` 结构（在 `AGENTS.md` 主题 bullet + `docs/theme-guide.md` 钩子表补充，作公开主题 API），默认背景用 `var(--panel-bg)` 派生，主题可覆盖。

### 5. 测试
新增 `turn-summary.test.ts`：单轮 / 多轮切分、assistant 连续合并、thinking/tool-call/图片排除、空会话、超长截断与省略号、user 消息无后续 assistant 的兜底。

## 验证方式
- `npm test`（新增用例 + 确认 `chat-layout.test`/`store.test` 不受影响）全绿。
- `npm run build` 全绿。
- 纯渲染端 + 一个可单测的纯函数；不改主进程/协议/现有主题钩子语义（新增钩子仅作扩展，不破坏既有）。

## 风险与假设
- "一轮"以 user 消息为锚点：若某轮用户提问后有连续多次工具调用才给出回复（`groupAssistantMessages` 已合并为一条 assistant），仍归同一轮，符合直觉。
- 点击跳转会改变粘底状态：只在用户主动点击导航时 `stickToBottomRef=false`，之后若用户又滚到底部会自动恢复粘底。
- hover 浮出卡片可能被右侧预览面板/Dock 遮挡：导航条贴时间线右缘、浮出卡片向左弹出（`right` 定位），并设 `z-index` 低于 dialog、高于时间线内容，与既有 menu-pop-in 一致。

- 缩略图形态：默认**右侧垂直 minimap 条**；若你更想要「每轮旁边嵌一个小图标」或「顶部横向条」，批准时说明即可。
- 点击行为：默认**点击滚动到该轮**。
